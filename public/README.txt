========================================================================
KATHAVAHINI — SITE LOGO UPLOAD FOLDER
========================================================================

📁 Directory Path:
/public/

🖼️ Recommended File Name:
logo.png
(or logo.svg / logo.webp)

Full file path:
/public/logo.png

------------------------------------------------------------------------
HOW TO UPLOAD:
1. Save your site logo image as "logo.png" (transparent PNG or SVG recommended).
2. Place or upload the file into the "/public/" folder in this project root.
3. The website's navigation bar, mobile header, footer, and admin screens
   will automatically load and display your logo immediately!
